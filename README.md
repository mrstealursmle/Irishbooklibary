# IRISH — Private Library & Archive

Standalone HTML website featuring:
- Animated archival double-door entrance interface
- Built-in soothing generative ambient music (Web Audio API, no external MP3 required) with top-bar Sound On/Off toggle
- All 5 full HTML manuscripts embedded directly inside `index.html` (no extra folders needed)
- Archival Daylight & Obsidian Night reading themes
- Built-in no-code Author Studio (`Shift + E` on desktop or append `?studio=1` to your URL)

## Quick Deploy

### Netlify Drop (Fastest)
1. Unzip this package (or keep `index.html` inside a folder).
2. Open your site on Netlify -> **Deploys** tab -> drag and drop the folder containing `index.html`.

### GitHub Pages
1. Upload `index.html` to the root of your GitHub repository.
2. Go to **Settings -> Pages -> Deploy from a branch** (`main` / `root`) and click **Save**.
